SPATIAL BUFFER QUERY PRO - QGIS PLUGIN

Cai dat:
1. Giai nen SpatialBufferQueryPro.zip.
2. Chep thu muc SpatialBufferQueryPro vao thu muc plugin QGIS:
   Windows: %APPDATA%\\QGIS\\QGIS3\\profiles\\default\\python\\plugins
3. Mo QGIS > Plugins > Manage and Install Plugins > Installed.
4. Bat "Spatial Buffer Query Pro".
5. Mo Vector > Spatial Buffer Query Pro.

Su dung:
1. Chon lop Vector.
2. Nhap ban kinh (met).
3. Bam "Click de chon diem tren ban do", sau do click tren ban do.
4. Neu muon xuat file, chon .geojson hoac .shp.
5. Bam "THUC HIEN TRUY VAN".

Ghi chu:
- Plugin tao he toa do Azimuthal Equidistant cuc bo quanh diem click de tinh Buffer theo met.
- Lop du lieu goc khong bi chinh sua.
- Kiem tra CRS va du lieu dau vao truoc khi su dung trong cong viec chinh thuc.
- Nen thu nghiem tren ban sao du lieu truoc.
